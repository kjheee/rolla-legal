# Rolla 공개 안내 문서

Rolla 앱의 정책 초안과 지원 문서를 관리하는 공개 저장소입니다. 앱 소스·자격 증명·사용자 데이터는 포함하지 않습니다.

## 공개 주소

- https://kjheee.github.io/rolla-legal/
- `/terms/`: 이용약관 초안
- `/privacy/`: 개인정보 처리방침 초안
- `/support/`: 고객 지원
- `/delete-account/`: 이메일 계정 삭제 요청 안내

GitHub Pages는 main 브랜치의 루트에서 Jekyll로 게시합니다. Markdown 수정 후 push하면 다시 배포됩니다. 각 경로의 끝 슬래시 없는 주소는 같은 문서로 이동합니다.

## 정식 출시 전 확정

- [ ] 시행일과 앱의 약관 동의 버전 일치
- [ ] 신고·문의·접속 로그·백업·Discord 사본 보관 기간과 실제 파기 절차
- [ ] Supabase 리전, 외부 서비스 계약 및 국외 이전 고지
- [ ] 계정 삭제 서버 배포, Apple 해지, Storage 삭제, 재가입 검증
- [ ] 이메일 수신 및 삭제 요청 본인 확인·처리 절차 검증
- [ ] 콘텐츠 필터링과 아동 안전 운영 기준
- [ ] 검토 완료 후 정책의 초안 표시 제거

초안 페이지의 HTTP 200은 스토어 제출 준비 완료를 의미하지 않습니다. 확정 전에는 정식 정책으로 제출하지 않습니다.
